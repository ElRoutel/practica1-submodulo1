# 2º Parcial – Práctica 1 – Investigación

## 1. Costos de páginas web (tablas, formularios, listas, imágenes, colores, página dividida)
En México una página básica o empresarial cuesta aproximadamente de $2,200 a $8,000 MXN, y una tienda en línea desde unos $5,000 a $25,000 MXN, según la complejidad. Si la haces tú, el costo baja a dominio (aprox. $250–$500 MXN al año) y hosting ($400–$4,000 MXN al año). Cada elemento extra (formularios con base de datos, galerías, secciones) aumenta las horas de trabajo y el precio.

## 2. Código para una página con índice de temas
Ver `indice.html` (anclas `href="#id"` hacia secciones con `id`).

## 3. Código para una página de ventas
Ver `ventas.html` (catálogo en tabla, imágenes y formulario de pedido).

## 4. Servicios de internet
Dominio, hosting (gratuito, compartido, VPS, dedicado, nube), certificado SSL, correo con dominio, pasarelas de pago y mantenimiento.

## 5. Software para crear páginas web
Editores: Bloc de notas, Notepad++, VS Code. CMS: WordPress. Constructores: Wix, Tiendanube, Shopify. Imágenes: GIMP, Canva.
